# Aura Flowers × Toucans Chocolate

One-page bilingual (EN/AR) website. Everything editable lives in the `CONFIG` block at the top of `index.html`.

- Photos: replace files in `img/` with the same names.
- Language links: `/EN`, `/AR` (or `?lang=ar`).
- Orders open WhatsApp pre-filled — set `whatsapp` in CONFIG.
